- simple way of storing data
	- tables and rows
- SQL - standard query language

represents data as *collection of tables*
- table = [relation] 
- tuple = [row]
- header = set of all [attribute]s (all columns together); one attribute = one column
relation schema - describes a table [relation]
degree - number of [attributes] in [relation schema]  (how *wide* — columns)
cardinality - number of [row]s  (how *tall* — rows)

tables link by key (not by nesting):
- primary key
- foreign key
 database - stores records in tables, and connects tables to each other by matching key values, on demand via joins.
